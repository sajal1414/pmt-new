Logos printed at the top of every course PDF (Courses > Download PDF).

  hazdemy.png  shown on the LEFT
  ibm.png      shown on the RIGHT

- PNG (transparent background works best) or JPG; the names must be exactly hazdemy / ibm.
- Each logo is scaled to fit 150 x 30 points (about 5.3 x 1 cm) and keeps its shape,
  so a wide, high-resolution image (for example 600 x 120 px) looks sharpest.
- They sit on a white strip, so dark or coloured logos are fine.
- Replace a file at any time; the next PDF download uses it (no restart needed).
- If a file is missing, the PDF is still created without that logo.
